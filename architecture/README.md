# Architecture Diagrams

- `sentinel-x-arch.mmd` - Mermaid source for the full platform diagram.

The platform diagram is embedded directly in the root [`README.md`](../README.md) as a
Mermaid code block, which GitHub renders natively — no PNG export is required.

## Rendering elsewhere
Paste the `.mmd` contents into https://mermaid.live to view or export an image, or in
VS Code install the "Markdown Preview Mermaid Support" extension and preview the file
directly.

> Note: `sentinel-x-arch.mmd` is the full **target** architecture and includes org-gated
> reference components (VPC-SC, Cloud IDS, Chronicle, SCC). See
> [`../docs/deployment-status.md`](../docs/deployment-status.md) for what is deployed vs.
> reference.
